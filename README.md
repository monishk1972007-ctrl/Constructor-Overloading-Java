# Constructor Overloading in Java

## Task
Implement Constructor Overloading in Java.

## Objective
To understand constructors and constructor overloading by creating a Java class with multiple constructors.

## Concepts Used
- Java Constructors
- Constructor Overloading
- Classes and Objects
- Instance Variables
- Method

## Program
The Student class contains multiple constructors with different parameters.

### Constructors Used
1. Student()
2. Student(String name)
3. Student(String name, int age)
4. Student(String name, int age, String department)
